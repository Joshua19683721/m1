📖 Learning English Takes Time

A2 Key 主題 Education  ｜  108 課綱會考 so that／in order that、too...to、enough to、so...that

🇨🇳 故事中文全文對照翻譯 (Story Chinese Translation)

【第一段】 我的英文測驗分數三個月來都沒有變化，我感到非常擔心。我翻開舊筆記本，發現作業裡有太多錯誤。老師說我光靠閱讀還不夠聰明，學不好英語。
【第二段】 我的朋友 Amy 幫我訂了一套讀書計畫，讓我能夠進步。我每天查字典、練習朗讀，並把新句子寫下來，好讓自己的發音更好。
【第三段】 現在我每天放學後會花二十分鐘複習課本和筆記本。我每晚做一點練習，也慢慢看見了實質的進步。上個月我的測驗分數高得讓班上每位同學都笑了起來。
My English test mark stayed the same for three months, and I felt quite worried.
🔍 文法與句法結構分析：
1. stay 的過去式 (stayed)： stay 是規則動詞，過去式直接加 -ed；若用一般現在式，主語 My English test mark 為單數，須寫 stays。
2. 並列連接詞 (and)： and 連接兩個完整句子，中間加逗號；此處前句寫「事實」、後句寫「感受」，語意層次遞進。
3. ⚠️ 陷阱：「感到擔心」用 feel + 形容詞（✓ felt worried），不可寫成 ✗ I felt worry。
I opened my old notebook and found too many mistakes in my homework.
🔍 文法與句法結構分析：
1. too + 形容詞 + 複數名詞 (too many mistakes)： too...to 的同義結構之一。too many 修飾可數名詞複數，too much 修飾不可數名詞，不可混用。
2. find 的過去式 (found)： find–found–found，過去式與過去分詞同形，是會考必背的不規則動詞。
3. ⚠️ 陷阱：「作業中的錯誤」用 mistakes in homework（in 表示在某範圍內），不可寫成 ✗ mistakes of homework。
Our teacher said that I was not clever enough to learn by reading alone.
🔍 文法與句法結構分析：
1. enough to + 動詞原形 (clever enough to learn)： enough 放在形容詞之後，to 後接原形 learn，整體表示「足以做某事」。
2. 否定式的位置 (was not clever enough to)： not 放在被否定的形容詞之前，否定整個 enough to 結構；⚠️ 陷阱：不可寫成 ✗ clever not enough。
3. 引述句型 (said that + 子句)： 間接引語語序為 that + 主語 I + 動詞，主語後必須用 be 動詞 was，不可倒裝。
🌉 段落文意銜接（第一段 ➔ 第二段）：
【情境說明】第一段先鋪陳主角的窘境：三個月的測驗分數原地不動，翻開舊筆記本才發現作業裡錯字連篇，老師更直接指出他光靠閱讀不夠。困頓累積到頂點，檢討讀書方法就成為全段轉折的起點。
My friend Amy helped me make a study plan in order that I could improve.
🔍 文法與句法結構分析：
1. help + 受詞 + 原形 (helped me make)： help somebody (to) do sth. 表示「幫助某人做某事」；此處 to 省略，直接接動詞原形 make。
2. 目的狀語從句 (in order that)： in order that = so that，表示目的，從句用「情態動詞 + 主語 + 原形」：in order that I could improve。
3. ⚠️ 陷阱：in order to + 原形也可以表目的，但兩者不可混用（✓ in order that I could improve）。
I look up new words in a dictionary and practise reading aloud every day.
🔍 文法與句法結構分析：
1. look up + 受詞 (look up new words)： 「查字典」是動詞 + 小品詞，in a dictionary 說明查詢的工具，是 A2 Key 高頻搭配。
2. practice / practise 的分工： 動詞一律寫 practise（practise doing sth.），名詞才寫 practice（do some practice）。
3. ⚠️ 陷阱：read aloud 是固定搭配「出聲地唸出來」，aloud 本身就是副詞，前面不可再加 loud 或 loudly（✗ read loudly aloud）；單獨用 loudly 雖也是正確副詞（read loudly），但朗讀課文時的慣用說法是 ✓ read aloud。
I write each new sentence down so that I can pronounce it well.
🔍 文法與句法結構分析：
1. write + 受詞 + down (write it down)： down 是小品詞，代詞 it 必須放在 down 之前，不可寫成 ✗ write down it。
2. 目的狀語從句 (so that)： so that 與 in order that 同義，此處接 can + 主語 + 原形，表示「為了能夠唸準」。
3. can + 動詞原形 (can pronounce)： 情態動詞 can 後面只能接原形動詞，pronounce 的重音在第二音節。
🌉 段落文意銜接（第二段 ➔ 第三段）：
【情境說明】第二段寫出朋友 Amy 的介入與整套讀書計畫，並用查字典、朗讀、寫句子三個具體動作說明「原來可以這樣學」。有了方法與規律，第三段才有可能出現成績與心態的雙重進步。
Now I review the textbook and my notebook for twenty minutes after school.
🔍 文法與句法結構分析：
1. review + 受詞 (review the textbook)： review ＝「複習」，是 A2 Key 高頻動詞；複習的對象直接放在動詞後當受詞。
2. for + 一段時間 (for twenty minutes)： for 後接時間段表示「持續多久」；⚠️ 陷阱：「在某個時刻」才用 at（✗ at twenty minutes）。
3. 時間狀語的位置： 表示持續長度的時間狀語可放句尾；移到句首時後面要加逗號。
Every night I do a little practice, and I slowly make real progress.
🔍 文法與句法結構分析：
1. 頻率狀語置於句首 (Every night)： every + 單數名詞 (every night)：every 後面直接接單數可數名詞 night，絕不可再加 of（✗ every night of，要加 of 須寫 every one of the nights）；置於句首表示頻率時後面加逗號，謂語用一般現在式 do。
2. a little + 不可數名詞 (a little practice)： a little 是肯定語氣「一點點」；單用 little 才是否定語氣「幾乎沒有」。
3. make progress (make + 名詞)： progress 此處為不可數名詞，前面不可加 a；⚠️ 陷阱：✗ make a progress → ✓ make progress。
Last month my test mark was so high that everyone in our class smiled.
🔍 文法與句法結構分析：
1. 結果狀語從句 (so + 形容詞 + that)： so 修飾形容詞 high，that 之後是結果，語序為「主語 + 動詞」不倒裝。
2. so 的位置 (so high)： so 必須緊貼它所修飾的形容詞之前，不可寫成 ✗ high so。
3. ⚠️ 陷阱：so...that（結果）與 so that（目的）不同：後者 that 前必須另有形容詞或副詞，本句 so high that 表結果。

📝 第 27 課 核心重點解析總整理 (Mastery Summary)

本課故事聚焦四組國中會考必考的目的與結果句型，以及 dictionary、notebook、textbook 這組校園學習核心詞的用法：

文法句型 目的與結果句型解析

  • 1. too...to / enough to：
    • ✓ He is too tired to study.（太累而無法讀書，否定）
    • ✓ He is clever enough to learn.（聰明到足以學會，肯定）
    • ⚠️ 陷阱：too 與 enough 位置互換即語意相反，不可寫成 ✗ enough tired to。
  • 2. so + 形容詞 + that（結果）：
    例句： My test mark was so high that everyone smiled.
    • that 後是結果，用陳述語序（everyone smiled）。
    • ⚠️ 陷阱：不可寫成 ✗ so high so everyone smiled。
  • 3. so that / in order that（目的）：
    • ✓ I wrote it down so that I could pronounce it well.
    • ✓ She made a plan in order that I could improve.
    • 從句用「情態動詞 + 主語 + 原形」，兩片語意思相同。
  • 4. too many / too much / too little：
    • too many + 可數複數（too many mistakes）
    • too much + 不可數（too much time）
    • too little + 不可數，表示「太少」。

搭配詞 讀書方法高頻搭配詞

  • make a study plan：制訂讀書計畫（make a + 計畫類名詞）。
  • look up a word in a dictionary：在字典裡查單字（固定結構，不可換成 in the dictionary look up）。
  • read aloud / practise reading：朗讀／練習朗讀（read 是動詞，reading 在此為動名詞）。
  • review / make progress：複習／有進步（progress 不可數，不加 a）。
  • test mark / after school：測驗分數／放學後（mark 為英式用法，指分數）。

詞彙辨析 容易寫錯的學習用詞

  • practice / practise：
    • practice (n.) 名詞：do some practice。
    • practise (v.) 動詞：practise reading aloud.
    • ⚠️ 陷阱：動詞拼作 -ise 形，不可寫成 ✗ practice reading。
  • mistake / mark：
    • mistake ＝「錯誤」，可數，a mistake / many mistakes。
    • mark ＝「分數」，可數，a test mark。
    • 兩者皆可數，但意思不同，會考常互換出題。
  • look for / look after / look up：
    • look for ＝「尋找」。
    • look after ＝「照顧」。
    • look up ＝「查字典」。三者皆為 A2 Key 必考片語。
