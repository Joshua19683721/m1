📖 Learning with AI

A2 Key 主題 Communication and Technology ／ Education  ｜  108 課綱會考 because / so 論述與科技倫理

🇨🇳 故事中文全文對照翻譯 (Story Chinese Translation)

【第一段】 上個星期一，我們班開始使用一個人工智慧工具來完成作業。同學小玲在電腦上打開軟體，點開第一個網頁。答案立刻出現在螢幕上，全班都非常興奮。
【第二段】 那個工具可以線上運作，所以只用了一個晚上，我就把專題作業做完了。我順手做了一則短短的筆記，因為我以為它每一門科目都懂。這次月考的分數，比我上個月好太多了。
【第三段】 然而有一天，我印出了一張寫著錯誤知識的紙頁。老師讓全班知道，機器也會犯錯。現在我仍然使用那個工具，但我會自己查核每一個答案，因為我真的想學會。
Last Monday, our class began to use a new AI tool for homework.
🔍 文法與句法結構分析：
1. begin / start + to + 原形 (began to use)：begin ＝ start，「開始做某事」後面接 to do；也可以用 begin + doing，兩者都正確，會考寫作建議用 begin to do。
2. 一般過去式 (began)：故事敘述已發生的事，故用 began。⚠️ 陷阱：不可寫成 ✗ begin to use（時態未變）或 ✗ began to using。
3. for + 名詞 (for homework)：for 表目的「為了」，後面接名詞或動名詞（for homework／for reading），不可直接接原形動詞。
My friend opened the software on her computer and clicked on the first web page.
🔍 文法與句法結構分析：
1. click (on) + 賓格 (clicked on the first web page)：click ＝「點（滑鼠）」，可說 click a link，也可說 click on a link，兩者都正確。
2. 不可數名詞 software：software 不可數，用 the software／a piece of software，⚠️ 陷阱：不可寫成 ✗ a software 或 ✗ the softwares。
3. 複合名詞的層級 (web page)：web page ＝「網頁」，website ＝「網站」，web ＝「網路」，三者不可互相替換。
The answers appeared on the screen, and the whole class felt very excited.
🔍 文法與句法結構分析：
1. 連繫動詞 + 形容詞 (felt very excited)：feel ＝「感到」，本句後面接形容詞 excited；feel 也可接 well／badly 這類描述身體狀況的副詞。
2. the + 集合名詞 (the whole class)：the whole class ＝「全班」，class 在此視為單數，謂語用單數動詞。
3. 並列完整句 (…, and …)：and 連接兩個各自完整的句子，兩個謂語都要符合各自的主語。
🌉 段落文意銜接（第一段 ➔ 第二段）：
【情境說明】第一段先讓新工具登場：軟體、網頁與螢幕把「科技」的樣貌一次說清楚，而答案秒回的驚奇，恰好為第二段的便利埋下伏筆。第二段順著主角的使用經驗推進，線上作業與專題成果都靠 so 成立，分數變好讓這種吸引力來到最高點。
The tool worked online, so I did my project with it in one evening.
🔍 文法與句法結構分析：
1. 結果連接詞 so：so ＝「因此、所以」，前句是原因、後句是結果；⚠️ 陷阱：原因用 because、結果才用 so，兩者方向相反不可互換。
2. do 的過去式 (did)：本句的 did 是實義動詞 do 的過去式（do–did–done），後面接受詞 my project；只有當 did 作助動詞時，後面的動詞才一律用原形（Did you use it?），不可寫成 ✗ Did you used it。
3. 表示耗時的片語置於句尾 (in one evening)：do + 賓格 + in 一段時間，是會考寫作加分的結構。
I made a short note, because I thought it knew every subject.
🔍 文法與句法結構分析：
1. 原因連接詞 because：because ＝「因為」，後面接原因；與 so（結果）方向相反，兩者不可互換，這組對比是會考標配。
2. think + that 子句 (thought it knew …)：think 表看法，子句要用陳述句語序（that it knew），⚠️ 陷阱：不可寫成 ✗ thought that did it know。
3. make 的過去式與可數名詞 (made a short note)：make–made–made（不規則三態），note 是可數名詞，前面須加冠詞與形容詞 a short。
My marks in the test were much better than last month.
🔍 文法與句法結構分析：
1. 比較級 + than (much better than)：單音節形容詞加 -er（good–better）；修飾比較級的 much 放在比較級之前。
2. than 後接比較對象 (than last month)：than 後接時間名詞時直接用 last month，不必加 the（than the last month 也可接受）；但比較特定對象時仍要保留 the（taller than the other boys），不可一概說 than 之後都不加 the。
3. be 動詞與複數主語一致 (marks … were)：主語 My marks 為複數，be 動詞用 were，不可寫成 ✗ My marks was。
🌉 段落文意銜接（第二段 ➔ 第三段）：
【情境說明】第二段末的驚喜在第三段被推翻：那一頁錯誤知識立刻打破「工具一定正確」的想像，老師一句「機器也會犯錯」就是全篇的轉折。最後主角用 but 與 because 把主動權拿回來，讓 AI 從替代者變成助手，故事因此漂亮收束。
Then one day I printed a page with a wrong fact about my subject.
🔍 文法與句法結構分析：
1. with + 名詞 (with a wrong fact)：with ＝「帶著、附有」，後面接名詞；要表示「關於某主題」則要用 about。
2. 規則過去式 (printed)：print 的過去式仍是 printed（加 -ed），重音不變；其分詞為 printing。
3. 指示副詞 Then 引出轉折：Then one day 承接前文的順利，用來提示接下來要發生變化。
The teacher showed the class that the machine could make mistakes too.
🔍 文法與句法結構分析：
1. show + 人 + that 子句 (showed the class that …)：show somebody (that) … ＝「讓某人知道」；間接敘述的子句一律用陳述句語序。
2. 情態動詞 could + 原形 (could make mistakes)：could 是 can 的過去式，後面只能接原形 make。
3. too 的位置：too 用來補充前面已提過的資訊，通常置於句尾或緊接所修飾的字詞之後，不可插在句首。
Now I still use the tool, but I check answers because I want to learn.
🔍 文法與句法結構分析：
1. 轉折連接詞 but：but ＝「但是」，前後語意相反；此處表示「工具照用，但答案要自己查」。
2. 原因連接詞 because：because ＝「因為」，後面接原因，與 so（結果）方向相反，這組對比是會考標配。
3. want to + 原形 (want to learn)：want ＝「想要」，後接 to do；若用 want that… 則句子不正確。

📝 第 52 課 核心重點解析總整理 (Mastery Summary)

本課故事聚焦 because 與 so 的因果對比、敘事用一般過去式，以及科技工具使用的倫理判斷：

文法句型 because／so 因果論述與敘事時態

  • 1. 因果連接詞 because 與 so：
    例句： The tool worked online, so I finished it in one evening.
    because 接原因（回答 why），so 接結果（回答 what happened next），⚠️ 陷阱：不可寫成 Because the tool worked online, so I finished it.
  • 2. 間接敘述 that 子句：
    • 完整型：The teacher showed the class that the machine could make mistakes。
    • 看法子句：because I thought (that) it knew every subject。
    • ⚠️ 陷阱：子句不可倒裝成 ✗ that did it know。
  • 3. 敘事時態的選擇：
    • 一般過去式：敘述已發生的事（I printed a page）。
    • 一般現在式：說明習慣或長久事實（I still use the tool）。
    • 不規則動詞必背三態：begin–began–begun、know–knew–known、find–found–found。
  • 4. 比較級與 be 動詞一致：
    • 比較級：much + better + than（than 後接時間名詞時不加 the）。
    • 主謂一致：主語 marks 為複數，be 動詞用 were。
    ⚠️ 陷阱：✗ My marks was better。

搭配詞 AI 學習情境高頻搭配詞

  • begin to + 原形：開始做某事（begin to use a new tool）。
  • click on + 賓格：點擊螢幕上的東西（click on the web page）。
  • do one's homework / do a project：做作業／做專題研究。
  • check + 賓語：查核、確認（check the answers）。
  • work online / open the software：線上運作／開啟軟體。

詞彙辨析 容易混淆的科技與校園用詞

  • software / information / data：
    • software ＝「軟體」（不可數）。
    • information ＝「資訊」（不可數，不加 -s）。
    • data ＝「資料」（字尾雖是 -a，用法同不可數）。
  • subject / mark / note：
    • subject ＝「科目」（每一門課）。
    • mark ＝「分數」（測驗成績）。
    • note ＝「筆記」（可數，take notes）。
  • click / press / touch：
    • click on ＝「用滑鼠點」。
    • press ＝「用手指按（鍵）」。
    • touch ＝「觸碰（螢幕）」，三者不可混用。
