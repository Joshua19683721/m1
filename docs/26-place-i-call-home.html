📖 The Place I Call Home

A2 Key 主題 Places: Countryside ／ Places: Town and City  ｜  108 課綱會考 關係副詞 where／when／why 引導定語從句、名詞性從句

🇨🇳 故事中文全文對照翻譯 (Story Chinese Translation)

【第一段】 去年夏天，我回到度過童年的那個村莊。那是我祖父蓋起一間小木屋的地方。一條河從房子後面流過，花園裡還有一棵老樹。
【第二段】 我在以前睡覺的房間裡找到一個箱子。裡面有一封祖母二十年前寫的信。信上說，她希望我記得自己是從哪裡來的。
【第三段】 如今我住在城市裡一棟二十多層的高樓，但村莊仍然是我最感到快樂的地方。每當我疲倦時，我就會想起那棵樹，然後繼續走下去。
Last summer I went back to the village where I spent my childhood.
🔍 文法與句法結構分析：
1. 關係副詞 where 引導定語從句（會考核心）：where ＝ in which / at which，後面接完整句子，用來修飾地點。
　the village where I spent my childhood
⚠️不可寫成 the village where did I spend（不可倒裝）。
2. spent（spend 的過去式）：spend–spent–spent，三態皆不規則。
3. spend time (on) + 對象：one's childhood 是不可數名詞，前面須加物主代詞 my。
It was the place where my grandfather built a small wooden house.
🔍 文法與句法結構分析：
1. It was + the place where...：整句為強調句的簡化說法，強調「那個地方」，是會考閱讀常見的起句。
2. where 引導定語從句：where 在句中充當狀語（＝ at which），後面接主詞與動詞。
3. built（build 的過去式）：build–built–built，為會考必背不規則動詞。
The river ran behind the house, and there was an old tree in the garden.
🔍 文法與句法結構分析：
1. 方位介系詞 behind：behind ＝「在⋯的後面」，是描述鄉間位置的必備介系詞（對照 in front of）。
2. There was + 單數名詞：there be 的過去式；an old tree 為單數，故用 was。
3. a / an 的選擇 (an old tree)：a 與 an 依後接名詞的讀音決定：old 的首音是母音 /oʊ/，所以用 an old tree；單音節與否與冠詞的選擇無關。
🌉 段落文意銜接（第一段 ➔ 第二段）：
【情境說明】第一段以 where 引導的定語從句構成全課骨架：先說「哪個村莊」，再說「那個地方」，最後說「房子後面」，層層收束，讓空間描寫有了清晰層次。
I found a box in the room where I used to sleep.
🔍 文法與句法結構分析：
1. used to + 原形：used to ＝「過去常常⋯⋯（現在不再）」，後接原形動詞，且沒有第三人稱單數變化（✗ he use to sleep）。
2. where 引導定語從句：the room where I used to sleep ＝「我以前睡覺的房間」。
3. find 的過去式 (found)：find–found–found，過去式與過去分詞同形。
Inside it was a letter that my grandmother had written twenty years ago.
🔍 文法與句法結構分析：
1. 地點狀語置前倒裝 (Inside it was a letter...)：為了強調地點而將 Inside it 放在句首，主語 a letter 後置、動詞提到主語之前，是 A2 閱讀常見的文體變化。
2. that 引導定語從句：that 指代前面的 a letter，在句中充當受詞（had written that／it）。
3. 過去完成式 (had written)：had + 過去分詞，表示「在找到箱子之前就已經寫好了」；twenty years ago 為過去時間。
The letter said that she wanted me to remember where we came from.
🔍 文法與句法結構分析：
1. 間接引語 (said that + 子句)：子句主語 she，謂語 wanted 保留原時態。
2. want sb to + 原形 (wanted me to remember)：want ＋ 人 ＋ to do，to 不可省略（對照 make／let／have 接原形）。
3. 間接問句 (where we came from)：「疑問詞 + 主詞 we + 動詞 came」的陳述語序，不可寫成 where did we come from。
🌉 段落文意銜接（第二段 ➔ 第三段）：
【情境說明】第二段把時間與地點交錯使用：房間（where）、二十年前（時間狀語 ago）、哪裡來（where）。找到的信件成為串起過去的實體，也讓抽象的記憶有了具體的載體。第三段則把村莊與高樓並置，完成從故鄉到現在生活的對照。
Now I live in a tall building in the city, which has more than twenty floors.
🔍 文法與句法結構分析：
1. 現在式描述現況：Now + 現在時，說明目前的居住狀態。
2. 非限定關係子句 (which has...floors)：which 指代前面的名詞 a tall building（＝「這棟大樓有二十多層」），前有逗號；後面不可再加逗號。
3. more than + 數字：more than ＝「超過」，是數量表達的高頻結構。
But the village is still the place where I feel happiest.
🔍 文法與句法結構分析：
1. But 表轉折：儘管住在高樓，村莊仍是最讓我快樂的地方，形成對照。
2. the place where + 完整句：where 在句中作地點狀語，後接「主詞 I + 動詞 feel」。
3. 最高級修飾語 (feel happiest)：happy 的最高級為 happiest；feel 後可直接接最高級形容詞。
Whenever I feel tired, I remember the tree, and I carry on.
🔍 文法與句法結構分析：
1. Whenever + 從句：whenever ＝「每當⋯⋯」，後接一般現在時的子句，作為時間狀語（表讓步要用 no matter when／even if）。
2. feel + 形容詞 (feel tired)：feel 為連繫動詞，後接形容詞描述身心狀態。
3. carry on + 動名詞：carry on ＝「繼續」，後接 V-ing（carry on walking）；單獨使用則不加任何詞。

📝 第 26 課 核心重點解析總整理 (Mastery Summary)

本課是關係副詞 where／when／why 與名詞性從句的專題。這兩者在會考閱讀的長篇測驗中出現頻率極高，卻常被忽略。

文法句型 關係副詞 where／when／why 與名詞性從句

  • 1. 關係副詞 where / when / why：
    • where ＝ in which / at which（地點）：the village where I was born.
    • when ＝ at which / on which（時間）：the day when we met.
    • why ＝ for which（原因、理由）：the reason why he left.
    ⚠️三者後面一律接完整句子，且不可倒裝。
  • 2. 限定與非限定關係從句：
    • 限定（無逗號，說明「是哪一個」）：the room where I used to sleep.
    • 非限定（有逗號，補充說明整件事）：I live in a city, which is very big.
    • 限定句中不可再用逗號；非限定句末尾不可再加逗號。
  • 3. 名詞性從句（整個子句當名詞）：
    • that / which / who 可引導：I know that she is right.／the house which I love.
    • where / when / why 也可引導名詞性從句：I remember where we met.
    • 在一般句中，that 常可省略；但作主詞時不可省略。
  • 4. 間接問句與從句的語序：
    • 間接問句：疑問詞 + 主詞 + 動詞（remember where we came from.）
    • ✗ remember where did we come from.
    • 與限定從句的 where 用法規則相同，只是位置不同。

搭配詞 回憶與家鄉情境搭配詞

  • go back to + 場所：回到⋯⋯（to 不可省略）。
  • spend one's childhood (in) + 地方：在某地度過童年。
  • used to + 原形：過去常常⋯⋯（現在已不）。
  • more than + 數字：超過⋯⋯。
  • carry on + V-ing：繼續做某事。

詞彙辨析 從句與介系詞易混點

  • where / which 的差別：
    • where 在從句中作狀語（＝ in/at which）：the town where I live.
    • which 在從句中作主詞或受詞：the book which I read.
    • 若從句中已有名詞作主語，就用 where。
  • used to / be used to / get used to：
    • used to do ＝ 過去常常做（現在不做了）
    • be used to + 名詞／V-ing ＝ 習慣於⋯⋯
    • get used to + 名詞／V-ing ＝ 開始習慣於⋯⋯
    • ⚠️be／get 後的 to 是介系詞，後接動名詞。
  • spent / spent（過去式）與 spend：
    • spend ＝ spend（花費／度過）
    • spent 是其過去式，兩者拼寫相同但詞性不同
    • spend + 時間／金錢 + on/for + 對象。
