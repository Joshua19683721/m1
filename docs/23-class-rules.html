📖 Class Rules and Suggestions

A2 Key 主題 Education ／ Personal Feelings, Opinions and Experiences  ｜  108 課綱會考 祈使句（肯定／否定）、建議句型 Let's／Why don't／How about、反意疑問句

🇨🇳 故事中文全文對照翻譯 (Story Chinese Translation)

【第一段】 我們的教室一直很吵，於是老師在黑板上寫了幾條新規則。我們必須把聲音壓低，而且在走廊上不可以跑。老師問我們是否同意這些規則，我們便分成小組討論。
【第二段】 我的朋友 Amy 建議我們每堂課後都擦黑板。有些同學希望多開窗，另一些則覺得教室太冷。於是我建議午休後安靜地閱讀十分鐘。
【第三段】 我們決定把新規則試行一週。下週一我們一起來看看成效，好嗎？就算忘記也別擔心，只要盡力就好，第二天再告訴我就行。
Our classroom was always noisy, so our teacher wrote some new rules on the board.
🔍 文法與句法結構分析：
1. be + 副詞 + 形容詞 (was always noisy)：noisy 為 A2 Key「Personal Feelings」形容詞；always 置於 be 動詞之後。
2. 規則 + 連接詞 so：因為教室一直很吵，所以老師寫了新規則，形成因果。
3. some + 複數可數名詞 (some new rules)：some 用於肯定句；new 置於 rules 之前作修飾。
We must keep our voices down, and we must not run in the hallway.
🔍 文法與句法結構分析：
1. 情態動詞 must + 原形 (must keep)：must ＝「必須」（表示規定或義務），後接原形 keep，不可寫 kept。
2. keep...down ＝ 壓低聲音：keep 是 A2 Key 極高頻的片語動詞（keep quiet／keep clean／keep fit）。
3. must not + 原形 (must not run)：must not ＝「不可以」，禁止；對照 don't have to ＝「不必」，兩者意義完全不同。
Our teacher asked us whether we agreed with the rules, and we talked about them in groups.
🔍 文法與句法結構分析：
1. 間接問句 whether (asked us whether we agreed)：whether（＝if）引導的是 yes/no 疑問的間接形式，語序為「whether + 主詞 we + 動詞 agreed」，不倒裝。
2. agree with + 人／物：agree with ＝「同意某人的看法」，對照 agree on（就某事達成共識）。
3. talk about + 對象 (them)：them 為代詞，替代前面的 the rules，避免重複。
🌉 段落文意銜接（第一段 ➔ 第二段）：
【情境說明】第一段從「教室很吵」這個具體問題切入，用兩條 must 開頭的規則直接示範「規定」與「禁止」兩種情態動詞句型（We must…／We must not…）。老師最後問「是否同意」，把規則從單方面宣布變成需要被討論的議題，為第二段鋪路。
My friend Amy suggested that we should clean the board after every lesson.
🔍 文法與句法結構分析：
1. suggest + 建議內容：
• 表「建議」：suggest that sb (should) + 原形（suggested that we should clean）
• 表「暗示」：suggest that + 陳述語序（His face suggested that he was angry.）
⚠️ 兩者絕不可混用。
2. after every lesson：every + 單數名詞 ＋ after，＝「每堂課之後」。
3. should + 原形 (should clean)：should 表建議，後接原形。
Some students wanted to open the windows more often, while others thought the room was too cold.
🔍 文法與句法結構分析：
1. more often：often 的比較級為 more often，＝「更頻繁地」。副詞比較級的規則：單音節副詞加 -er（如 hard → harder），多音節或 -ly 結尾的副詞前加 more + 原級（如 quietly → more quietly）；often 是特例，雖是單音節卻加 more。
2. while 作對比：while 在此不表示時間，而表示然而、另一方面，連接兩種相反的意見。
3. too + 形容詞 (too cold)：too 表「太⋯⋯（超出可接受範圍）」，與 merely very 不同。
So I suggested reading quietly for ten minutes after lunch.
🔍 文法與句法結構分析：
1. suggest + 動名詞：suggest 表「建議」時，後可直接接 V-ing：suggested reading；與 suggest that sb (should) do 意思相同。
2. for + 一段時間：for ten minutes ＝「十分鐘」，對照 at ten o'clock（時間點）。
3. quietly：副詞修飾動詞 read，說明「以安靜的方式閱讀」。
🌉 段落文意銜接（第二段 ➔ 第三段）：
【情境說明】第二段是全班意見的呈現：Amy、一部分同學、主角各有主張，形成三種不同聲音。第三段則把討論收束成「試行一週」的具體行動，並以建議語氣作結，讓故事停在「開始實踐」而非「討論完成」的位置。
We decided to try the new rules for a week.
🔍 文法與句法結構分析：
1. decide to + 原形 (decided to try)：decide 後接不定詞，是 A2 Key 必收句型。
2. try + 名詞：try the rules ＝「試試看新規則」；對照 try to do（試著做某事）與 try out（試訓）。
3. for a week：表示試行的時間長度。
Let's see the result next Monday, shall we?
🔍 文法與句法結構分析：
1. Let's + 原形 (Let's see)：Let us 的縮寫，後接原形動詞，表示提議「我們來⋯⋯吧」。
2. 附加問句 (shall we?)：對 Let's...、Let us... 的建議，用 shall we? 徵求同意；對 How about...?／Why don't we...? 的疑問句，回答才用 OK, let's...。
3. 時間副詞置於句中：next Monday 放在動詞 see 與句末問號之間，不影響主句語序。
Don't worry if you forget; just do your best and tell me the next day.
🔍 文法與句法結構分析：
1. 否定祈使句 (Don't worry)：祈使句的否定直接加 Do not / Don't，句首不加主語 you。對照肯定祈使句（祈使句一律省略 you）。
2. if + 現在式 (if you forget)：if 引導條件子句時，謂語用一般現在式，不可寫成 if you will forget。
3. 分號 (;)：分號連接兩句獨立的祈使句，是會考標點與句型合併的高頻考點。

📝 第 23 課 核心重點解析總整理 (Mastery Summary)

本課是祈使句與建議句型的專題：會考寫作中「提出建議」的段落幾乎必用這組句型，也是口語表達「我們一起⋯⋯吧」的核心架構。

文法句型 祈使句與建議句型（Let's／Why don't／How about）

  • 1. 祈使句的三種形式：
    • 肯定：直接用原形動詞開頭，省略 you：Keep quiet.（✗ You keep quiet. 作祈使句）
    • 否定：句首加 Don't / Do not：Don't run in the hallway.
    • 禮貌：Please + 原形，或用 could/would：Could you close the door?
  • 2. 三組建議句型：
    • Let's + 原形, shall we?：Let's see the result, shall we?
    • Why don't we + 原形?：Why don't we take a photo?
    • How about + 名詞 / What about + V-ing?：How about Friday?／What about going together?
    ⚠️Let's 後接原形，Why don't 後接原形，What about 後接 V-ing。
  • 3. must not 與 don't have to：
    • must not ＝ 禁止（不可以⋯⋯）：You must not run.
    • don't have to ＝ 不必（可以不⋯⋯）：You don't have to clean it.
    • 兩者中文都可能被誤譯為「不必」，是會考超級高頻陷阱。
  • 4. suggest 與 suggest that：
    • 建議：suggest doing／suggest that sb (should) do
    • 暗示：suggest that + 陳述語序
    • ⚠️suggest（建議）不接 that 子句的「原形省略 should」以外的任何變化。

搭配詞 校園規範情境搭配詞

  • keep + 形容詞／副詞：保持某狀態（keep quiet／keep tidy／keep fit）。
  • agree with sb / agree on sth：同意某人的看法／就某事達成共識。
  • talk about + 對象：談論⋯⋯。
  • try + 名詞／try to do／try out：試試看⋯⋯／試著做⋯⋯／試訓。
  • do one's best：盡力而為（best 為不可數名詞，不加 a）。

詞彙辨析 情態與祈使句易混點

  • noisy / quiet / tidy / polite：
    • noisy ＝ 吵鬧的　• quiet ＝ 安靜的
    • tidy ＝ 整潔的　• polite ＝ 有禮貌的
    • 這四個都來自 A2 Key Personal Feelings 主題，是校園規約題的常見用詞。
  • agree 的三種搭配：
    • agree with sb ＝ 同意某人：I agree with you.
    • agree on sth ＝ 就某事達成共識：We agreed on a plan.
    • agree to do ＝ 同意做某事：He agreed to help.
  • rule / rule 作動詞：
    • rules (n.) ＝ 校規、規則（複數形式）
    • rule (v.) ＝ 支配、統治
    • ⚠️兩者拼寫相同但詞性不同，須依句子判斷。
