📖 Camping in the Rain

A2 Key 主題 Weather ／ The Natural World ／ Hobbies and Leisure  ｜  108 課綱會考 if 條件句（第一類真實條件／第三類與過去事實相反的假設）、suggested that、because

🇨🇳 故事中文全文對照翻譯 (Story Chinese Translation)

【第一段】 去年暑假，我們班到山裡的一個湖邊露營。第一天，天氣晴朗，天空湛藍。領隊說，如果第二天早上不下雨，我們就去遠足。
【第二段】 下午，山丘上方出現了烏雲，風也變得更強了。如果我們有事先查過天氣預報，我們本來就會待在帳篷裡。他建議我們把食物放進箱子，並把帳篷搬到一個遮蔽處。
【第三段】 雨下了大約兩個小時，但沒有人被淋濕，因為我們的帳篷很安全。如果你要去露營，應該隨身帶著地圖、手電筒和保暖衣物。雨停的時候，空氣聞起來清新又乾淨，我們大家都覺得很放鬆。
Last summer, our class went camping beside a lake in the mountains.
🔍 文法與句法結構分析：
1. 不規則過去式 (went)：go–went–gone，與第 3、6 課的用法相同，可累積記憶。
2. beside + 場所：beside ＝「在⋯旁邊」，與 next to 語意相近但更強調緊貼。
3. go camping：camp 在此是動詞原形，go camping 是 A2 Key「Hobbies and Leisure」主題的固定片語；第 6 課的 stationery（文具）則屬「Shopping」主題，兩者不是同一主題。
On the first day, the weather was fine and the sky was blue.
🔍 文法與句法結構分析：
1. 天氣專用句型 (the weather was)：談天氣時不可加 a／an（✗ a fine weather），這是會考單選的固定陷阱。
2. be 動詞 + 形容詞：fine 與 blue 皆為形容詞，直接修飾天氣與天空。
3. How is the weather…? / What's the weather like…?兩種問法皆可，會考聽力與閱讀皆常出現。
Our leader said that we would go hiking early the next morning if it didn't rain.
🔍 文法與句法結構分析：
1. 未來式 (would + 原形)：would 後接原形 go，表示「將會⋯⋯」，後續仍可再加 if 條件句。
2. if 條件句第一類（真實條件）：if + 現在式, will / would + 原形——「如果⋯⋯就⋯⋯」。
3. ⚠️ 陷阱：第一類條件句的 if 從句中不可用將來式（✗ if it will not rain, we will go，改為 If it doesn't rain, we will go）；本課故事第 3 句之所以出現 if it didn't rain, we would go，是因為它被放進 said that 的間接敘述，will 往過去推移成 would。
🌉 段落文意銜接（第一段 ➔ 第二段）：
【情境說明】第一段用「藍天」與「條件句」建立一個近乎完美的期待，讓讀者先相信明天會是好天氣。第二段立刻用「烏雲」與「風更強」打破這個期待，是全篇最大的戲劇轉折。
In the afternoon, dark clouds appeared above the hills and the wind became stronger.
🔍 文法與句法結構分析：
1. 規則過去式 (appeared)：appear 以 e 結尾，只加 -d：appear–appeared–appeared。
2. become 的三態：become–became–become，為會考必背不規則動詞；become + 比較級 表示「變得更⋯⋯」。
3. 單音節 CVC 型形容詞比較級 (stronger)：strong 為單音節且是「子音＋母音＋子音」，須重複末尾的輔音再加 -er（strong–stronger）；多音節形容詞則加 more，與第 6 課的 expensive（more expensive）不同，須分組記憶。
If we had checked the weather report, we would have stayed in our tents.
🔍 文法與句法結構分析：
1. if 條件句第三類（與過去事實相反的假設）：if + had + 過去分詞, would have + 過去分詞——「如果（當初）⋯⋯就會⋯⋯（但實際沒有）」。
2. had + 過去分詞 (had checked)：此處不是第 2、3、6 課的「過去某時之前已完成」，而是第三類條件句的假設句型的一部分，兩種用法要分清楚。
3. would have + 過去分詞：表示「本來就會⋯⋯（但實際沒有）」，與第 6 課的 could have bought 屬同一概念。
He suggested that we put our food into boxes and move the tents to a shelter.
🔍 文法與句法結構分析：
1. suggest that + (should) + 原形：suggest ＝「建議」時，that 子句用原形動詞（此處省略 should）。
2. ⚠️ 會考超高頻陷阱：suggest 後一律接 that 子句，「建議」與「暗示／表明」的差別在子句內的動詞形式——
　• He suggested that we put…（建議 → 原形）
　• His face suggested that he was angry.（暗示 → 陳述語序） 3. put – put – put：put 的過去式與過去分詞都不變形，為必背特例；put 後接受詞與地點介系詞，構成 put the food into boxes。
🌉 段落文意銜接（第二段 ➔ 第三段）：
【情境說明】第三段回到結果：雨雖然下了，但因為有準備，眾人都安然無恙。故事用「帶什麼」的建議作結，把個人經驗轉化為可帶走的實用知識，正是閱讀測驗最喜歡的「由敘事歸納原則」考法。
It rained heavily for about two hours, but nobody got wet because our tents were safe.
🔍 文法與句法結構分析：
1. it 作虛主語 (It rained)：「下雨」等天氣現象以 It 開頭，it 本身不指任何具體事物。
2. be wet：wet 作形容詞（＝潮濕的），本句要表現「變濕」的動作所以用 got wet；若只描述狀態則用 were wet（be wet ＝ 是濕的）。
3. because 引導原因：與第 4 課的 but（轉折）搭配使用，形成「雖⋯⋯但⋯⋯因為⋯⋯」的完整因果邏輯。
If you go camping, you should always take a map, a torch and some warm clothes.
🔍 文法與句法結構分析：
1. if 條件句第一類 (If you go, you should take)：if ＋ 現在式（主語若為第三人稱單數，動詞仍要加 -s，如 If it rains, we should stay.），主句用 should + 原形；主句的動詞才是原形。
2. always 的位置：置於主要動詞 take 之前：you should always take。
3. 名詞作賓語 (some warm clothes)：clothes 為只有複數的名詞，永遠加 -s，且不可加 a。
When the rain stopped, the air smelled fresh, and we all felt relaxed.
🔍 文法與句法結構分析：
1. When + 短暫過去式：與第 3 課「When we left…」同型，短動作用一般過去式。
2. 感官動詞 + 形容詞 (smelled fresh)：smell 後接形容詞，不加副詞（✗ smelled very freshly）。
3. 連繫動詞 + 形容詞 (felt relaxed)：feel + 形容詞描述人的感受；relaxed 以 -d 結尾，故用 -ed 形式。

📝 第 7 課 核心重點解析總整理 (Mastery Summary)

本課把 if 條件句放進天氣敘事中，是會考「閱讀理解＋文意判斷」的典型考法：讀者必須分辨「真實條件」與「假設條件」。

文法句型 if 條件句：真實條件與過去假設

  • 1. 第一類：真實條件句（最常考）
    if + 現在式, will / would + 原形
    • 例： If it doesn't rain, we will go hiking.
    • ⚠️ 陷阱：if 從句不可用將來式，也不可讓第三人稱單數漏掉 -s。
  • 2. 第三類：與過去事實相反的假設
    if + had + 過去分詞, would have + 過去分詞
    • 例： If we had checked the report, we would have stayed in our tents.
    • 相當於中文「如果當初⋯⋯，就會⋯⋯（但實際沒有）」。
    • ⚠️ 別與第二類混淆：第二類＝與現在事實相反，句型為 if + 過去式, would + 原形（If it were fine, we would stay in our tents.）
  • 3. suggest 的兩種句型（超高頻陷阱）：
    • 建議：suggest that sb (should) + 原形（suggested that we put…）
    • 暗示：suggest that + 陳述語序（His face suggested that he was angry.）
    • 兩者絕對不可混用。
  • 4. 虛主語 it：
    • 天氣：It rained heavily.（下雨）
    • 時間／距離：It is ten kilometres.
    • 形式主語：It is important to learn English.

搭配詞 露營與天氣高頻搭配詞

  • go camping / go hiking：去露營／去遠足。
  • beside / above / in + 地點：在⋯旁邊／在⋯上方／在⋯之中。
  • check the weather report：查看天氣預報。
  • get wet：變成濕的（be wet ＝ 是濕的，兩者語意層次不同）。
  • take a map / a torch / warm clothes：攜帶地圖、手電筒、保暖衣物。

詞彙辨析 suggest 與易混淆字

  • put / put / put：put 的過去式不變（put–put–put），會考常以「是否加 -ed」出題。
  • wet 與 rained：
    • get wet ＝（人）變濕，強調動作
    • be wet ＝（狀態）是濕的
    • rain ＝ 雨（不可數名詞）／下雨（動詞）
  • clothes 與 clothing：
    • clothes ＝ 衣服（只有複數，不可加 a）
    • clothing ＝ 服裝（不可數，泛指）
    • a piece of clothing ＝ 一件衣服
